# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y este proyecto se adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-01-01

### Añadido
- Implementación del componente `modelo`: Carga de CSV (delitos y controles ISO 27001), validación de listas de chequeo y cálculo de cobertura y nivel de riesgo..
- Implementación del componente `informe`: Generación del informe de auditoría y análisis de brechas en formato Markdown clasificando riesgos y priorizando controles pendientes..
- Implementación del componente `__main__`: CLI para visualizar la matriz delito-control, exportar plantillas CSV de autoevaluación y ejecutar auditorías de brechas..
- Configuración de flujo de trabajo de integración continua.
- Documentación técnica, guías de arquitectura y políticas de seguridad.
